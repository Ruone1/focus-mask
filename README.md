# 🛡️ 极客屏幕防干扰遮罩 (Geek Screen Mask)

一个使用 Python 标准库 `tkinter` 纯手搓的极简屏幕遮罩工具。

它会在你的屏幕上生成一个无边框、半透明、永远置顶的悬浮条，非常适合在专注工作、学习时，用来遮挡网页上的干扰元素（如视频推荐栏、广告、或者不想看到的代码行）。

## ✨ 特性

* **零第三方依赖**：纯 Python 标准库编写，开箱即用。
* **沉浸式体验**：无边框设计，完美融入桌面。
* **丝滑拖拽**：按住鼠标左键，即可将遮罩拖动到屏幕任何位置。
* **一键关闭**：鼠标右键点击遮罩，瞬间关闭程序，深藏功与名。
* **高度可定制**：宽度、高度、颜色、透明度都可以在源码中一键修改。

## 🛠 环境准备

只需确保你的电脑已安装 Python 3.x 即可，无需安装任何 `pip` 依赖。

## 🚀 快速启动

### 方式一：命令行启动
在项目根目录下打开终端，运行：
```bash
python ws.py
```
### 方式二：无黑框启动(推荐)
如果你不想看到黑色的命令行窗口，直接双击项目目录下的 
ws.vbs
 文件即可无痕启动。
 ## 🕹️ 使用说明

1. **移动位置**：鼠标左键按住遮罩不放，即可拖动到任意位置。
2. **退出程序**：鼠标**右键**单击遮罩，程序即刻退出。

## ⚙️ 自定义配置

如果你想修改遮罩的外观，请用代码编辑器打开 `ws.py`，找到顶部的“配置区”：

```python
# ================= 配置区 =================
WINDOW_WIDTH = 700   # 遮罩的宽度（你可以自己改）
WINDOW_HEIGHT = 30   # 遮罩的高度（你可以自己改）
BG_COLOR = "gray"    # 遮罩的颜色（纯黑填 "black"）
ALPHA = 0.85         # 透明度（1.0 完全不透明，0.0 完全透明，0.85 是磨砂效果）
